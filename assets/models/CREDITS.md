# Model credits (Fieldwork XR Practice Lab realism pass)

Every glTF/GLB file under `assets/models/` is listed here with its author, source page, and license. All are **CC0 1.0 (public domain)**,
so no credit is required; it is given anyway. `training-simulations/test/models.test.mjs` fails if a file is missing from this table
or a listed file does not exist. Nothing here is loaded from the network at run time.

License checks (read on 2026-11-03):

- Poly Haven: https://polyhaven.com/license says "Our assets are all licensed as CC0" and that credit is not required.
- Quaternius: the pack page https://quaternius.com/packs/universalbasecharacters.html states CC0, and each model page on Poly Pizza
  (links below) shows "Public Domain (CC0)" with Quaternius as author. The people are from the Quaternius
  "Ultimate Animated Character Pack" family (idle/walk/run/sit clips). The files were downloaded from the Poly Pizza model pages,
  because the Quaternius download goes through an itch.io page that cannot be fetched from a script. The license statement checked
  on the Quaternius site was for its Universal Base Characters pack page; the Poly Pizza pages are the per-model evidence for these files.
