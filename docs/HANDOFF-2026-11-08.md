## How it is built

- `vive-steamvr/packages/com.pittbradford.xrtraining/Runtime/XRBackend.cs`: `XRBackends` with `Rig` and `Grab` hooks. The kit's `XRRig`, `Hand` and `Grabbable` were patched to use them.
- `Runtime/SteamVR/SteamVRBackend.cs` (separate asmdef, compiled only with the `PB_STEAMVR` define): builds Valve's Player and Teleporting prefabs, puts the kit's `Hand` on Valve's hands, adds one TeleportArea over the training area, wraps each `Grabbable` with Valve's `Throwable`. With no headset it steps aside and the kit's own desktop rig is used.
- `vive-steamvr/steamvr-setup/SteamVRProjectSetup.cs` and `scripts/setup-steamvr.ps1`: plugin 2.8.5b import, two-file patch (PhysicMaterial to PhysicsMaterial), Steam Input actions from Valve's example, OpenVR loader, Direct3D 11, the `PB_STEAMVR` define. Plugin folders are git-ignored; the script restores them.
- `scripts/steamvr-simulator.ps1` (`-Enable`, `-Disable`, `-Status`, `-Run <exe> -Shot <png> -Seconds N`): turns on SteamVR's null-driver simulated headset and runs a build with a screenshot. Passes `-pbHeadOffset 1.6` because the simulated headset reports height 0.
- Tooling notes: builds need `-accept-apiupdate` (otherwise the API Updater dialog blocks); do not use `Start-Process -Wait` with Unity (a lingering UnityCrashHandler64 hangs it; scripts use WaitForExit and kill it); write `manifest.json` without a BOM.
