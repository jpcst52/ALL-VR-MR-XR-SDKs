# Talk track: 15 minutes

An outline, not a script. It makes no claims about results, outcomes or savings: say only what you showed and what you verified.

| Min | Segment | Do / say |
|---|---|---|
| 0-2 | Why | The program builds hands-on XR practice for general safety awareness. Examples are practice, not a procedure or certification. Scenarios are generic and inspired by regional industry; do not name companies. Name the audience's interests as questions, not promises. |
| 2-4 | What runs where | One lab PC serves browser-based lessons (the 17-scenario Practice Lab and three multiplayer themes) to Quest headsets over the local network; a Vive Pro 2 on SteamVR shows the Unity lobby and scenarios. The browser parts need no internet; only the optional live wind in Refinery Rounds does. |
| 4-7 | Multiplayer demo: Circuit Lab | Two or three guests join one room by QR code, build a circuit together, toggle a switch. Point out the shared state and that each guest appears to the others as a character in a hard hat. |
| 7-9 | Site Safety Layout | Place exits, extinguishers, barriers as a team; discuss the layout choices rather than "correct" answers. |
| 9-12 | Vive: lobby and a scenario | One person in the Vive while others watch the monitor: walk the lobby, step on a portal, then one scenario (for example the Hydrostatic Test Bay). Describe it as a training scenario inspired by industrial testing; no procedural claims, no claims about learning results. |
| 12-14 | Where this goes | Ask partners which scenarios would be useful; mention research ideas only as plans (see `docs/research/`). |
| 14-15 | Close | Next steps, contact, invite hands-on time. |
