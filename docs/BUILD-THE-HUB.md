# Building the hub (lobby and all four scenarios)

The hub is the one SteamVR build that reaches every Vive example: it opens in a lobby, and you walk onto a portal to load Hydrostatic Test Bay, Refinery Rounds, Warehouse and Forklift or Resistor Bench. Projects 01 to 04 build from a plain checkout. **The hub does not**, because most of what is in it is licensed and kept out of git. This page says what is missing and how to get a hub build on any PC.

General safety-awareness practice only; none of the scenarios is a procedure or certification.

**Honest status.** The hub was built and started on the author's PC on 2026-11-08 (`builds\vive\hub\XRTrainingHub.exe`, about 1 GB, about 10 minutes). It was run windowed with no headset: it loads the lobby, the lobby music starts and there were no exceptions. The two routes below for a **second PC have not been tried**: the copy route (A) is the dependable one; route B follows the author's own procedure but was not replayed from an empty project.

## What is in git and what is not

`vive-steamvr\hub\.gitignore` commits only our own code and settings: `Assets\Editor`, `Assets\Scripts`, `Assets\Settings`, `Assets\XR`, `ProjectSettings`, `Packages`. Everything else under `vive-steamvr\hub\Assets` (about 3.0 GB, 4,971 files on the author's PC) is local only:

| Local folder in `hub\Assets` | What it is | Size | Source |
|---|---|---|---|
| `IGBlocks` | warehouse art (`IG_Warehouse`) | 719 MB | Asset Store, publisher **IG BLOCKS**, "Big Warehouse Pack" |
| `SciFi Warehouse Kit` | walls, floors, props, skybox textures | 482 MB | Asset Store, publisher **Sickhead Games**, "Sci-Fi Construction Kit (Modular)" |
| `Warehouse` | modular warehouse pieces | 237 MB | Asset Store, publisher **Gamevio**, "Modular Warehouse" |
| `Courtyard Props` | construction lights, fuel containers, power generator (5 prop folders) | 233 MB | Unity "The Courtyard 3D Sample Project" (publisher Unity Technologies), the five folders under `Meshes\Props` named below |
| `Modern Office` | desks, chairs, plants, office props | 145 MB | Asset Store, publisher **3D Everything**, "Modern Office" |
| `Shipping Container` | shipping containers and crates | 70 MB | Asset Store, publisher **SimpleModelsForMe**, "ShippingContainer" |
| `Rocketbox` | realistic people and their animations | about 1.1 GB | Microsoft Rocketbox Avatar Library, MIT license, https://github.com/microsoft/Microsoft-Rocketbox (cite Gonzalez-Franco et al. 2020, doi 10.3389/frvir.2020.561558) |
| `Scenes\Local` | the five hub scenes (`Lobby`, `HydrostaticTest_Hub`, `RefineryRounds_Hub`, `WarehouseForklift_Hub`, `ResistorBench_Hub`) | 30 MB | generated by the hub's editor builders |
| `Baked` | the baked scene data and lobby floor tiles | 29 MB | generated by **Bake scene** |
| `Resources` | two shader-variant materials | 14 KB | generated by the kit |

The pack names above were matched by comparing the folders on the author's PC with the contents of the cached Asset Store packages on that PC (each package contained the folder named in the table). The Asset Store sells and updates packs on its own schedule, so a newer version may differ; the author's copies are the tested ones. The licenses of these packs do not allow redistributing the files, which is why the repository, GitHub Pages and the combined `XR-Training-Vive-<date>.zip` never contain them. **Never upload the hub build, the pack zip or any of these folders.**

Courtyard props used (inside the sample project at `Assets\Unity Technologies\The Courtyard\Meshes\Props\`): `Construction Light`, `Construction Light Floor`, `Fuel Container Red`, `Fuel Container Yellow`, `Power Generator`.

Rocketbox avatars used (from the library's `Avatars` folder; each with its `Export` and `Textures` folders): `Adults\Female_Adult_03`, `Adults\Male_Adult_05`, `Professions\Business_Female_01`, `Business_Male_01`, `Construction_Female_01`, `Construction_Male_01`, `Construction_Male_02`, `Construction_Male_04`, `Delivery_Male_01`, `Medical_Female_01`, `Security_Male_01`; and the animation folders `Animations\all_animations_max_motextr_static` and `Animations\all_animations_max_motextr_xy`, plus `LICENSE.md`. They must sit under `Assets\Rocketbox` (the editor scripts look there). The other packs' prefabs are found by name anywhere under `Assets`, and a missing pack is skipped with a log line.

## Route A (recommended): copy the files from the PC that has them

On the PC that has the hub files (the author's lab PC):

1. Double-click **`scripts\pack-hub-assets.cmd`**. It zips every local-only file, including the `.meta` files (they hold the asset IDs the scenes refer to, so a copy without them breaks the scenes), into `builds\hub-assets-<date>.zip` (about 3 GB of files, 2,084 MB zipped on 2026-11-08; `-DryRun` through `scripts\hub-assets.ps1 -Pack -DryRun` shows the list first). It takes a few minutes.
2. Move the zip to the other PC by USB drive or local network. It holds licensed files: do not upload it or put it in a shared cloud folder.

On the PC that will build:

3. Install **Unity Hub** and **Unity 6000.3.20f1** with *Windows Build Support (Mono)*. `git pull` this repository.
4. Close every Unity editor. Drag the zip onto **`scripts\unpack-hub-assets.cmd`**. It extracts into `vive-steamvr\hub\Assets`.
5. Run **`scripts\check-build-pc.cmd`** (checks Unity, disk space, the hub files and the network; changes nothing), then double-click **`scripts\build-all-vive.cmd`** (all five players) or run `powershell -ExecutionPolicy Bypass -File scripts\build-vive.ps1 -IncludeHub -Projects hub` for the hub alone. The scenes are already built and baked, so nothing needs to be opened in Unity first. The first Unity run on a new PC imports about 3 GB of assets into its `Library` folder, so expect it to take noticeably longer than the author's 10 minutes (not measured).
6. The result is `builds\vive\hub\XRTrainingHub.exe` with `hub.zip` beside it. Copy that folder to the VR Stage PC. Keep it off GitHub.

If the build script says the hub's scenes or art are missing, step 4 did not complete or went to the wrong folder; the script lists exactly what it did not find.

## Route B: rebuild everything from the sources

Use this if no PC has the files. It follows the hub's own procedure (also in `vive-steamvr\hub\README.md` and `docs\HOW-TO-RUN.md`), but was not replayed from an empty project, so expect to fix small things.

1. Install Unity 6000.3.20f1 with Windows Build Support (Mono) and `git pull` the repository.
2. Get the packs in the table from the Unity Asset Store (they must be in your account's *My Assets*; the Courtyard sample is free) and Rocketbox from GitHub. Create the hub project once by opening `vive-steamvr\hub` in Unity Hub, then in the editor use *Window > Package Manager > My Assets* to import each pack into the hub project. For the Courtyard sample import only the five prop folders named above. Copy the Rocketbox folders listed above into `Assets\Rocketbox` (keep the library's folder names).
3. Menu **Pitt-Bradford > Set up hub project** (once; the settings are already committed, so this normally changes nothing).
4. Menu **Pitt-Bradford > People > Set up Rocketbox controllers** (makes the looping idle and walking clips and the small animation controllers under `Assets\Rocketbox\Controllers`).
5. Menu **Pitt-Bradford > Build hub: lobby and all scenarios**. This writes the five scenes to `Assets\Scenes\Local` and registers them in Build Settings with `Lobby` first. A missing pack is skipped with a log line.
6. Open each of the five scenes in turn and run **Pitt-Bradford > Bake scene (play mode)** (about 15 seconds each). Rebuilding the scenes removes the bake, so do this after step 5.
7. Menu **Pitt-Bradford > Hub: static-batch the baked scenes (run after baking)**.
8. Close the editor and run `scripts\build-all-vive.cmd`, or the hub-only command in route A step 5.

The hub's build step (`vive-steamvr\hub\Assets\Editor\HubBuild.cs`) also lists the season-sky shader under Always Included Shaders before each build; nothing to do by hand.

## What to check after building

- Start SteamVR first, then run `XRTrainingHub.exe`. It opens in the lobby: thumbnails on four portals, a sky photo, music starting after a few seconds (press M on a desktop to mute).
- Teleport (push a thumbstick or the trackpad forward, release), then stand on a portal pad for about 1.4 seconds to load a scenario. Hold both grips for 1.5 seconds (or Backspace on a desktop) to return to the lobby.
- None of this has been tried in a headset yet. The hub was only run windowed on a desktop with no headset.
