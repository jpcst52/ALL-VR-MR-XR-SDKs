# Credits: the four single-SDK web demos

Covers `threejs/` (Prism Bloom), `a-frame/` (Orbit Garden), `babylonjs/` (Luminous Totem) and `webxr/` (Color Field). All of it is offline: every file below is in this repository and nothing is fetched at run time. `tools/vr-capture/demos-check.mjs` fails if a file a demo loads is missing here.

## Licence check

On 2026-11-03 the Poly Haven licence page (<https://polyhaven.com/license>) said its assets are "all licensed as CC0 ... effectively Public Domain", and each asset page below was fetched the same day and carries the line "CC0 1.0 Universal - public domain dedication, no attribution required". CC0 1.0 deed: <https://creativecommons.org/publicdomain/zero/1.0/>. Attribution is not required; it is given anyway. Author names come from the Poly Haven API (`https://api.polyhaven.com/info/<id>`).
