# Example screenshots

Captures of the four single-SDK browser examples, re-shot with `node tools/vr-capture/demos-shots.mjs` (desktop 1440 x 900 in Chrome with software GL, with the optional logo blocked so the text wordmark shows). The "VR not supported / unavailable" buttons are the real desktop state: **these are not headset recordings.** Each example folder also has an `...-emulated-quest3.png` taken inside an **emulated** Meta Quest 3 session (Meta's IWER runtime); it is not a real headset either.
